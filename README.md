# أقِم صلاتَك — منصة تعلّم بالتلعيب (بأسلوب كاهوت)

تطبيق تعليمي تفاعلي لمنهج **«أقم صلاتك بشروطها وأركانها وواجباتها»**. يستضيف المعلّم جلسة ويعرض رمز **PIN**، وينضمّ الطلاب من أجهزتهم ويتنافسون في الإجابة على أسئلة مؤقّتة (اختيار من متعدد + صح/خطأ)، مع احتساب النقاط حسب الصحة والسرعة وترتيب لحظي ومنصّة فائزين.

ألوان الواجهة مستخرجة من ملف العرض الأصلي (زيتوني/فيروزي/كريمي مع لمسات عنّابية وذهبية).

## الأقسام الأربعة
1. **الطهارة (الوضوء)** — صفة الوضوء، التنبيهات، المسح على الجورب، التيمم وغسل الجنابة.
2. **الصلاة (أفعالها)** — أفعال وهيئات الصلاة كاملة والتنبيهات الشائعة.
3. **الأركان والشروط والواجبات** — التعريفات والفروق والعدّ وأحكام الترك.
4. **المبطلات والسنن والآداب** — مبطلات الصلاة، السنن القولية والفعلية، والآداب.

## البنية
```
server/   خادم Node + Express + Socket.IO (الجلسات والنقاط)
  data/   بنك الأسئلة (JSON) — مصدر الحقيقة ويحوي الإجابات الصحيحة
client/   واجهة React + Vite (المضيف واللاعب) بدعم RTL
```

## التشغيل المحلي
يتطلب Node.js 18+.

```bash
npm run install:all     # تثبيت تبعيات الخادم والواجهة
npm run dev             # تشغيل الخادم (3001) والواجهة (5173) معًا
```

ثم افتح `http://localhost:5173`:
- **المعلّم:** «استضافة جلسة» → اختر القسم → اعرض رمز PIN على الشاشة.
- **الطلاب:** «الانضمام بِرمز» على أجهزتهم → أدخل الرمز والاسم.

> للاستخدام داخل الصف على الشبكة المحلية، شغّل الواجهة بعنوان جهاز المعلّم على الشبكة، أو ابنِ الواجهة وقدّمها من الخادم (انظر النشر).

## النشر — الحصول على رابط تفاعلي مباشر
النمط الجماعي يحتاج خادمًا دائم التشغيل يدعم WebSocket (لا يكفي الاستضافة الثابتة مثل GitHub Pages). المشروع مهيّأ للنشر بنقرة واحدة.

### الخيار الأول: Render (مجاني، موصى به)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/omaraldawood49-alt/-)

1. اضغط الزر أعلاه، وسجّل الدخول إلى Render بحساب GitHub (مجاني، بلا بطاقة).
2. سيقرأ Render ملف `render.yaml` تلقائيًا (الفرع، أوامر البناء والتشغيل، وفحص الصحة) — اضغط **Apply**.
3. انتظر اكتمال البناء (~2–3 دقائق)، وستحصل على رابط حيّ مثل: `https://aqim-salatak.onrender.com`.

> ملاحظة: الخطة المجانية في Render تُنيم الخدمة بعد فترة خمول، فيتأخّر أول طلب ~30 ثانية ثم تعمل بسرعة.

### الخيار الثاني: أي منصّة حاويات (Railway / Fly.io / Cloud Run)
يوجد `Dockerfile` جاهز:
```bash
docker build -t aqim-salatak .
docker run -p 3001:3001 aqim-salatak     # ثم افتح http://localhost:3001
```
على Railway: «Deploy from GitHub repo» → يكتشف الـ Dockerfile تلقائيًا. تأكّد من اختيار الفرع `claude/islamic-curriculum-gamification-2blx3m`.

### النشر اليدوي (أي خادم Node)
```bash
npm run install:all     # تثبيت التبعيات
npm run build           # بناء الواجهة في client/dist
npm start               # الخادم يقدّم الواجهة على المنفذ PORT (افتراضيًا 3001)
```

## تحرير الأسئلة
كل قسم ملف JSON في `server/data/`. شكل السؤال:
```jsonc
{
  "id": "معرّف-فريد",
  "type": "mcq",            // "mcq" أو "truefalse"
  "question": "نص السؤال",
  "options": ["خيار1", "خيار2", "خيار3", "خيار4"],
  "correctIndex": 0,         // فهرس الإجابة الصحيحة (يبدأ من 0)
  "explanation": "شرح مختصر يظهر بعد الكشف",
  "source": "مصدر السؤال من المنهج"
}
```
لأسئلة صح/خطأ: `"type": "truefalse"` و`"options": ["صح","خطأ"]`. لإضافة قسم جديد سجّله في `server/data/index.js`.

## النقاط
إجابة صحيحة = حتى 1000 نقطة (نصفها أساس + نصفها مكافأة سرعة تتناقص مع زمن الإجابة)، والخطأ = 0. الإجابة الصحيحة لا تُرسل للّاعبين قبل انتهاء الوقت لمنع الغش.
