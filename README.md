# أقِم صلاتَك — منصة تعلّم بالتلعيب (بأسلوب كاهوت)

تطبيق تعليمي تفاعلي لمنهج **«أقم صلاتك بشروطها وأركانها وواجباتها»**. يستضيف المعلّم جلسة ويعرض رمز **PIN**، وينضمّ الطلاب من أجهزتهم ويتنافسون في الإجابة على أسئلة مؤقّتة (اختيار من متعدد + صح/خطأ)، مع احتساب النقاط حسب الصحة والسرعة وترتيب لحظي ومنصّة فائزين.

التطبيق **بلا خادم (serverless)**: تتم المزامنة اللحظية بين المعلّم والطلاب عبر **Firebase Realtime Database**، والواجهة تُستضاف على **Firebase Hosting** — رابط حيّ دائم ومجاني على خطة Spark. ألوان الواجهة مستخرجة من ملف العرض الأصلي (زيتوني/فيروزي/كريمي مع لمسات عنّابية وذهبية) بدعم RTL.

## الأقسام الأربعة (77 سؤالًا)
1. **الطهارة (الوضوء)** — صفة الوضوء، التنبيهات، المسح على الجورب، التيمم وغسل الجنابة.
2. **الصلاة (أفعالها)** — أفعال وهيئات الصلاة كاملة والتنبيهات الشائعة.
3. **الأركان والشروط والواجبات** — التعريفات والفروق والعدّ وأحكام الترك.
4. **المبطلات والسنن والآداب** — مبطلات الصلاة، السنن القولية والفعلية، والآداب.

## البنية
```
client/                واجهة React + Vite (التطبيق كاملًا) بدعم RTL
  src/firebase.js      تهيئة Firebase من متغيّرات البيئة
  src/game.js          منطق اللعبة فوق Realtime Database (المضيف هو المرجع للتصحيح)
  src/data/            بنك الأسئلة (JSON) + فهرس الأقسام
  src/screens/         Home / Host / Player
firebase.json          إعداد Hosting + قواعد قاعدة البيانات + المحاكي
database.rules.json    قواعد Realtime Database
.firebaserc            معرّف مشروع Firebase (استبدله بمعرّفك)
```

> **حماية الإجابات:** الأسئلة مع إجاباتها الصحيحة تبقى في متصفّح **المضيف** فقط، ولا تُكتب الإجابة الصحيحة في قاعدة البيانات إلا **بعد** انتهاء الوقت/الكشف، فلا يراها الطلاب أثناء السؤال. (ملاحظة: بنك الأسئلة ضمن حزمة الواجهة، فهذا مناسب لمراجعة صفّية لا لاختبار رسمي عالي الحساسية.)

## الإعداد محليًا
يتطلب Node.js 18+، ومشروع Firebase مفعّل فيه **Realtime Database**.

1. أنشئ مشروعًا على [console.firebase.google.com](https://console.firebase.google.com) → أضف **Web App** → فعّل **Realtime Database** (وضع الاختبار في البداية).
2. انسخ إعدادات الويب إلى ملف بيئة:
   ```bash
   cp client/.env.example client/.env
   # ثم املأ القيم في client/.env
   ```
3. ثبّت وشغّل:
   ```bash
   npm run install:all
   npm run dev            # http://localhost:5173
   ```

## النشر — رابط تفاعلي مباشر (Firebase Hosting)
```bash
npm i -g firebase-tools          # مرة واحدة
firebase login                   # بحسابك على Google
firebase use --add               # اختر مشروعك (يحدّث .firebaserc)
npm run deploy                   # يبني الواجهة ثم ينشر Hosting + قواعد القاعدة
```
بعد النشر تحصل على رابط حيّ مثل: `https://<project-id>.web.app`
- المعلّم: «استضافة جلسة» → اختر القسم → اعرض رمز PIN.
- الطلاب: يفتحون نفس الرابط → «الانضمام بِرمز».

## النشر التلقائي (GitHub Actions)
يوجد سير عمل في `.github/workflows/firebase-deploy.yml` ينشر تلقائيًا عند كل دفع للفرع.
لتفعيله، أضف **مفتاح حساب خدمة** كسرّ في المستودع (يعمل من الجوال عبر المتصفّح):
1. Firebase Console ← ⚙️ Project settings ← **Service accounts** ← **Generate new private key** (يُنزّل ملف JSON).
2. GitHub ← مستودعك ← **Settings ← Secrets and variables ← Actions ← New repository secret**.
3. الاسم: `FIREBASE_SERVICE_ACCOUNT` — والقيمة: الصق **محتوى ملف JSON كاملًا**.

بعدها كل دفعة (أو تشغيل يدوي من تبويب Actions) تنشر الموقع وقواعد القاعدة إلى `https://amir-1cb84.web.app`.

## لوحة إدارة الأسئلة
من الصفحة الرئيسية ← **⚙️ إدارة الأسئلة** (رمز المشرف الافتراضي `admin`، يُغيَّر عبر `VITE_ADMIN_CODE`).
تتيح اللوحة لكل قسم: استيراد أسئلة المنهج إلى Firebase، ثم الإضافة/التعديل/الحذف. التعديلات تُحفظ في
Realtime Database وتظهر فورًا في الجلسات الجديدة. إن لم يُستورد قسم بعد، تعمل اللعبة بأسئلة المنهج الافتراضية.

## تحرير الأسئلة (يدويًا)
الأسئلة الافتراضية في `client/src/data/` (تُستخدم كاحتياطي قبل الاستيراد). شكل السؤال:
```jsonc
{
  "id": "معرّف-فريد",
  "type": "mcq",            // "mcq" أو "truefalse"
  "question": "نص السؤال",
  "options": ["خيار1", "خيار2", "خيار3", "خيار4"],
  "correctIndex": 0,         // فهرس الإجابة الصحيحة (يبدأ من 0)
  "explanation": "شرح مختصر يظهر بعد الكشف",
  "source": "مصدر السؤال من المنهج"
}
```
لأسئلة صح/خطأ: `"type": "truefalse"` و`"options": ["صح","خطأ"]`. لإضافة قسم جديد سجّله في `client/src/data/index.js`.

## أنماط اللعب
- **الفصول (تراكمية):** الأقسام الأربعة هي الفصول بالترتيب (الطهارة ← صفة الصلاة ← الأركان والشروط والواجبات ← المبطلات والسنن). اختبار كل فصل تراكمي: يضمّ كل أسئلة الفصل الحالي + عيّنة من الفصول السابقة مع التركيز (~⅔) على الفصل الحالي.
- **فردي أو جماعي:** يختار مقدّم المسابقة عند الاستضافة. في الجماعي يحدّد **عدد الفِرَق (2–10)**، ويختار كل طالب فريقه عند الانضمام، وتُجمع نقاط الفريق ويظهر ترتيب الفِرَق.

## النقاط
إجابة صحيحة = حتى 100 نقطة (نصفها أساس + نصفها مكافأة سرعة تتناقص مع زمن الإجابة)، والخطأ = 0.
اللاعب الذي ينقطع أو يغلق التطبيق يعود ويواصل بنقاطه تلقائيًا (تُحفظ جلسته محليًا).
